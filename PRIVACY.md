# Privacy Policy - HMB MUSIC
1. **Data Collection:** We only collect necessary data to run the bot, such as Server IDs and User IDs for managing the music queue.
2. **Data Usage:** We do not sell or share any user data with third parties.
3. **Data Retention:** Cached music files are automatically deleted every 10 minutes.
4. **Contact:** If you have any questions, contact the developer through our support server.
