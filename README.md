# 🎶 HMB MUSIC - Discord Bot

**HMB MUSIC** بۆتەکێ موزیکێ یێ پێشکەفتی و ب‌هێزە بۆ سێرڤەرێن دیسکۆردێ. ئەڤ بۆتە هاتییە دیزاینکرن دا کو باشترین کوالیتیا دەنگی دابین بکەت و پشتەڤانییا هەمی پلاتفۆرمێن مەزن دکەت.

---

## ✨ تایبەتمەندیێن سەرەکی (Features)

*   **🎵 پشتەڤانییا فرە-سەکۆ:** لێدانا موزیکێ ژ (YouTube, TikTok, Spotify, SoundCloud).
*   **🕹️ کۆنترۆڵ پانێل:** لێدانا موزیکێ ب ڕێکا دوگمەیێن کارلێکەر (Pause, Resume, Stop, Volume).
*   **⚡ فەرمانێن هایبرید:** پشتەڤانی ژ هەر دوو جۆرێن فەرمانان دکەت: Slash Commands `/` و Prefix Commands `!`.
*   **♻️ پاقژکرنا ئۆتۆماتیکی:** سیستەمەکێ زیرەک بۆ پاقژکرنا داتایێن کاتی (Cache) هەر ١٠ خولەکان (تایبەت بۆ Fly.io).
*   **🚀 ب‌هێز و خێرا:** هاتییە گونجاندن دا کو ل سەر سێرڤەرێن وەک Fly.io ب بێ کێشە کار بکەت.

---

## 🛠️ تەکنەلۆژیا بکارهاتی (Built With)

*   [Python 3.10+](https://www.python.org/)
*   [Discord.py](https://discordpy.readthedocs.io/en/stable/)
*   [yt-dlp](https://github.com/yt-dlp/yt-dlp)
*   [FFmpeg](https://ffmpeg.org/) (بۆ چارەسەرکرنا دەنگی)

---

## 📋 فەرمانێن بۆتی (Commands)

| فەرمان | مەبەست |
| :--- | :--- |
| `/play` یان `!play` | لێدانا موزیکێ ب ڕێکا ناڤ یان لینک |
| `/stop` یان `!stop` | ڕاوەستاندنا موزیکێ و دەرکەفتنا بۆتی |
| **Control Buttons** | کۆنترۆڵکرنا دەنگی و ڕاوەستاندن ب دوگمەیان |
