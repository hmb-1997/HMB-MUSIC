# 🎶 HMB MUSIC - Discord Bot

**HMB MUSIC** بۆتەکێ موزیکێ یێ پێشکەفتی و ب‌هێزە بۆ سێرڤەرێن دیسکۆردێ، کو ب زمانێ Python هاتییە گەشەپێدان. ئەڤ بۆتە هاتییە دیزاینکرن دا کو کوالیتیا هەرە بلند یا دەنگی دابین بکەت و ب شێوەیەکێ ئۆتۆماتیک داتایێن کاتی پاقژ بکەت دا کو هەمیشە یێ خێرا بیت.

---

## ✨ تایبەتمەندیێن سەرەکی (Features)

*   **🎵 پشتەڤانییا فرە-سەکۆ:** لێدانا موزیکێ ژ (YouTube, TikTok, Spotify, SoundCloud).
*   **🕹️ کۆنترۆڵ پانێل:** کۆنترۆڵکرنا موزیکێ ب ڕێکا دوگمەیێن کارلێکەر (Pause, Resume, Stop).
*   **⚡ فەرمانێن هایبرید:** پشتەڤانی ژ Slash Commands `/` و Prefix Commands `!` دکەت.
*   **♻️ پاقژکرنا زیرەک:** سیستەمێ پاقژکرنا داتایێن کاتی (Cache) هەر ١٠ خولەکان بۆ پاراستنا سێرڤەری و خێراییێ.
*   **☁️ پشتەڤانییا Railway:** هاتییە ئامادەکرن دا کو ب بێ کێشە ل سەر Railway.app کار بکەت.

---

## 🛠️ تەکنەلۆژیا بکارهاتی (Built With)

*   [Python 3.10+](https://www.python.org/)
*   [Discord.py](https://discordpy.readthedocs.io/)
*   [yt-dlp](https://github.com/yt-dlp/yt-dlp)
*   [FFmpeg](https://ffmpeg.org/) (بۆ چارەسەرکرنا دەنگی ب کوالیتیا بلند)

---

## 📋 فەرمانێن بۆتی (Commands)

| فەرمان | مەبەست |
| :--- | :--- |
| `/play` یان `!play` | لێدانا موزیکێ ب ڕێکا ناڤ یان لینکا سترانێ |
| `/stop` یان `!stop` | ڕاوەستاندنا موزیکێ و دەرکەفتنا بۆتی ژ چەناڵی |
| **Control Buttons** | کۆنترۆڵکرنا (Pause, Resume, Stop) ب ڕێکا دوگمەیان |
