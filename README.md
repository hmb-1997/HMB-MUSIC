### 🌟 دەربارەی پڕۆژەی
**HMB MUSIC** بۆتەکێ موزیکێ یێ ب هێز و خێرا یە بۆ سێرڤەرێن دیسکۆردێ. ئەڤ بۆتە ب زمانێ **Python** هاتییە نڤیسین و هاتییە گونجاندن دا کو ل سەر سەکۆیا **Railway** ب باشترین کوالیتی کار بکەت. 

---

### ✨ تایبەتمەندیێن سەرەکی (Key Features)

*   **🎵 پشتەڤانییا فرە-سەکۆ:** لێدانا موزیکێ ژ یوتیوب، تیکتۆک، و چەندین جهێن دی.
*   **📂 لیستا ١٠٠ گۆرانیان:** فەرمانا `/yt_music` لیستەکا ئامادەکری یا ١٠٠ گۆرانیان پێشکێشی بەکارهێنەری دکەت.
*   **🕹️ کۆنترۆڵ پانێل:** ب ڕێکا دوگمەیێن (Pause, Resume, Skip, Stop) موزیکێ کۆنترۆڵ بکە.
*   **♻️ سیستەمێ پاقژکرنا زیرەک:** بۆ پاراستنا سێرڤەری ژ تژی بوون، هەر **١٠ خولەکان** ئۆتۆماتیک فایلێن کاتی (Cache) ڕەش دکەت.
*   **⚡ فەرمانێن هایبرید:** تو دشێی فەرمانێن Slash `/` یان Prefix `!` بکاربینی.

---

### 📋 فەرمانێن بۆتی (Commands)

| فەرمان | کارکرن |
| :--- | :--- |
| `/play` | لێدانا موزیکێ ب ڕێکا ناڤ یان لینک |
| `/yt_music` | نیشاندانا لیستا ١٠٠ گۆرانیێن ئامادەکری |
| `/stop` | ڕاوەستاندنا موزیکێ و چۆنە دەرێ |
| `/pause` | ڕاوەستاندنا کاتی یا موزیکێ |
| `/resume` | بەردەوامکرنا موزیکا ڕاوەستیا |
| `/skip` | چۆنە سەر سترانا داهاتی |
